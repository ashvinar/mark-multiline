# Source and binary scope

This repository is a development snapshot of an experimental modification for a retail Mark II. It includes newly written controller, analysis, build, and uploader source, plus the exact recovered manufacturer application and its patched form needed to reproduce the installed result.

The recovered application is not manufacturer source code, a frozen SDK source release, a full device image, or a verified recovery tool. Manufacturer code and names retain their existing ownership. No open-source license is assigned by this snapshot.

Raw scans, page photographs, camera replay recordings, device-specific Bluetooth identifiers, credentials, and local tool installations are excluded. The included historical timing fixture contains scalar measurements only. Replay summaries describe tests on recordings that are not redistributed here.
